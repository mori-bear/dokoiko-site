# 高品質Destination作成テンプレート

## 概要
destinations.jsonに「高品質な」目的地を追加するためのテンプレートとプロセス。
品質スコア上位30件の分析から導かれた標準パターン。

## 高品質パターン（30件の中央値）

| 項目 | 推奨値 | 備考 |
|------|--------|------|
| `description` | 50〜80字 | 「。」2つ以上、文学的トーン（別府/熱海風） |
| `spots` | 3〜4件 | 各spotに20〜60字のdescription |
| `tags` | 4〜6個 | 地理・自然・歴史・グルメ・季節を組合せ |
| `reasonChips` | 3個 | 「温泉がおすすめ」「ひとり旅向け」など用途別 |
| `travelTime` | 主要hubに10+件 | 実態の特急・新幹線・飛行機の所要時間 |
| 画像 | 主+各spot | UnsplashとWikipedia Commons |

## descriptionの書き方

### 良い例（別府・湯けむり描写）
> 湯けむりが路地を包み、硫黄の匂いが鼻をかすめる。地の底から湧き上がる熱が、冷えた体の芯まで溶かしていく、そんな街。

### 良い例（松山・道後と坂の上）
> 道後の湯気が朝の路地をぼかし、坂の上にゆらりと雲の影。3000年の湯と現存天守の城下町を、路面電車が一日かけて結ぶ、そんな街。

### パターン
1. **五感に訴える描写**（湯けむり/匂い/音/光）
2. **2文構成**：情景描写 → 街の本質
3. **終わり方**：「そんな街」「時間がここにある」「光景」「と織りなす」

## spotの書き方

各spotは以下を含む：
- `name`: 一般に通用する正式名（Wikipedia引きで画像取得）
- `description`: 20〜60字、固有名詞×特徴×時代/規模/技法を1〜2文で

### 良い例
```json
{
  "name": "道後温泉本館",
  "description": "日本最古とされる温泉。明治27年築の木造楼閣建築は国の重要文化財、夏目漱石「坊っちゃん」ゆかりの湯。"
}
```

## tagsの選び方
4〜6個、以下から多様性を持って選ぶ：
- 自然系: 海/山/湖/川/高原/絶景/紅葉/桜
- 文化系: 温泉/寺社/城/世界遺産/歴史/伝統
- 体験系: 街歩き/グルメ/酒/茶/アート/博物館
- 季節系: 春/夏/秋/冬/雪
- 立地系: 離島/秘境/リゾート

## reasonChipsの書き方
3個、ユーザーの選択シーンに直結する助言：
- `温泉がおすすめ`（温泉地）
- `城下町散策`（歴史都市）
- `ひとり旅向け`（落ち着き）
- `カップル向け`（夜景・絶景）
- `日帰り最適`（120分以内）
- `家族で楽しめる`（テーマパーク・水族館）
- `車なしOK`（公共交通完結）

## travelTimeの埋め方

### 必須カバー（13都市）
東京・大阪・名古屋・福岡・札幌・仙台・広島・高松・那覇・金沢

### 計算方法
- **新幹線**: JR時刻表＋15分（乗換・徒歩）
- **特急**: JR時刻表＋15分
- **飛行機**: 飛行時間＋空港アクセス両端60分
- **高速バス**: 公式時刻＋10分

## 作成プロセス

### 自動化されたスクリプト
`scripts/createQualityDestination.py` の `DEST_TEMPLATE` を編集 → 実行

スクリプトは以下を自動実行：
1. validate(): 字数・件数の検証
2. fetch_wikipedia_image(): 各spotの画像取得
3. fetch_unsplash_image(): 主画像取得
4. destinations.json に追加

### 手動検証チェックリスト
- [ ] JR時刻表（jr-odekake.net / ekitan）で travelTime 確認
- [ ] 公式観光協会サイトでspot名・住所確認
- [ ] Google Mapsで実在・営業時間確認
- [ ] 楽天トラベル/じゃらんでhotelKeyword検索結果確認
- [ ] Wikipedia/Unsplash画像が正しいものか目視確認

## 実例：松山（matsuyama）

実装は `scripts/createQualityDestination.py` の `DEST_TEMPLATE` を参照。

品質スコア: 110/110（30件中最高）
- description: 63字 / 「。」2つ / 文学的
- spots: 4件 / 各60字前後の説明 / 全件画像付き
- tags: 4個
- reasonChips: 3個
- travelTime: 14都市カバー
- Unsplash + Wikipedia画像両方取得
